# IEEE RAS AI Assistant

This repository contains the code and data for a deployed Retrieval-Augmented Generation (RAG) chatbot designed specifically for the IEEE Robotics and Automation Society (RAS).

Project Highlights:

Purpose: Provides accurate, context-aware answers regarding IEEE RAS memberships, conferences (like ICRA and IROS), and Technical Committees.

Architecture: Utilizes LangChain to process public IEEE RAS documentation and a persistent ChromaDB vector store for fast, local information retrieval.

User Interface: Features an interactive, pure-Python web interface built and deployed using Streamlit.

LLM Integration: Powered by advanced language models to synthesize retrieved text into natural conversational responses.
